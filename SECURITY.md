# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability. Report it privately to the repository maintainers using GitHub's private security advisory reporting feature, if enabled, or through the contact method published by the maintainers.

Include a clear description, affected component or version, reproduction steps, impact, and any suggested mitigation. Please avoid accessing data that is not yours or disrupting services while validating a report.

Maintainers will acknowledge reports, assess impact, and coordinate remediation and disclosure as appropriate. Do not include credentials, API keys, or sensitive data in reports.

## Supported versions

Only the latest version on the default branch is supported while the project is in its initial development phase.

See [docs/security.md](docs/security.md) for operational security guidance.
